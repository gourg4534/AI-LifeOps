# AI LifeOps

AI LifeOps is a lightweight AI-powered personal productivity and decision-support application.

## Goal

The project combines:

- Productivity management
- AI assistance
- Personal context
- RAG
- AI Agents
- Machine Learning
- FastAPI
- Database
- Frontend

## Constraints

- Zero build cost
- Lightweight architecture
- Project storage target: <= 1 GB
- No large local LLM
- No unnecessary dependencies
